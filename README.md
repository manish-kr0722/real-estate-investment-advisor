# Real Estate Investment Advisor
Predicts whether a property is a Good Investment and its estimated price after 5 years. Streamlit app: `streamlit run app.py`.
- `app.py` Streamlit app | `src/` preprocessing, EDA, training scripts | `models/` trained models | `outputs/` app data and metrics
- `Real_Estate_Investment_Advisor.ipynb` full notebook (EDA, training, evaluation) | `Project_Documentation.docx` report
Dataset: india_housing_prices.csv (not included, 41 MB).
